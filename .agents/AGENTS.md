# Project Rules & Guidelines

- **Clarification & Questioning**: Whenever the user submits a new prompt requesting a feature or change, first ask all necessary clarifying questions related to that feature to align on requirements before starting planning and integration.

- **Comprehensive Testing & Validation**: Whenever working on any feature, once completed, test it properly and check if there are any errors. If any errors are found, solve them and re-test iteratively until the feature is properly built, error-free, and fully verified.
